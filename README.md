# 👑 Royal To-Do CLI (`royal-todo-cli`)

A sleek, lightweight, and robust Command-Line Interface (CLI) To-Do application built with Python. Designed for speed, minimal aesthetic distraction, and reliable local task persistence.

---

## ✨ Features

* **Minimalist UI:** Clean bracket-only ANSI coloring for intuitive visual hierarchy without terminal clutter.
* **JSON Persistence:** Automatically saves and loads your tasks in a lightweight local `tasks.json` storage.
* **Robust UX:** Clear terminal screens on execution, seamless feedback messages on task changes, and graceful exit handling.
* **Zero External Dependencies:** Built entirely with standard Python modules for maximum portability and fast execution.

---

## 🚀 Quick Start

### Prerequisites
* Python 3.8 or higher installed on your system.

### Running the Application
1. Clone or download this repository.
2. Open your terminal in the project directory.
3. Run the application:
